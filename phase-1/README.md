# Phase 1 – Thinking Foundation

This phase is about building reasoning skills, not memorizing formulas.

## Focus areas
- Understanding why models fail
- Bias vs variance (conceptual, not mathematical)
- Assumptions behind models
- Data → Decision → Outcome pipeline

## Notes
Each note answers four questions:
1. What is the problem?
2. Why does it exist?
3. What usually goes wrong?
4. How could it be improved?
